## Códigos-para-ciencias-sociales
Códigos básicos para el análisis de datos para ciencias sociales

Aquí estaré compartiendo algunos de los códigos que me han funcionado para el análisis de datos para ciencias sociales. Van desde cosas sencillas hasta procesos más complejos según el tipo de datos y el propósito de su uso.
Ninguno de los códigos aquí almacenados representa o sustituye una clase completa. Simplemente son ilustrativos para aquellos que están familiarizados con la estadística y probabilidad.
Por ello, se asumirá un entendimiento desde lo básico hasta lo intermedio en estas materias.

#Lenguaje de programación: R (RStudio)
En cada ejercicio estaré mostrando las distintas paqueterías y funciones que se usaron.

La mayoría se trata de códigos que utilicé para mis clases y trabajos durante la maestría, así que estarán fuertemente inspirados en el trabajo de mis docentes. Otros, en cambio, fueron de mi propia creación según la investigación que estuviera realizando.


Espero que les sean útiles a todas y todos.
